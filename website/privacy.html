Dotlore

Privacy

No analytics, telemetry, crash reporting, accounts, or servers of its own. Your files never pass through anything run by Dotlore.

What the app sends over the network

  • Update checks. At launch, every six hours, and on "Check for Updates…", the app fetches latest.json from GitHub Releases. No identifier is sent; GitHub sees your IP.
  • Nothing else. No usage, project, or install reporting.

What stays on your Mac

  • Settings and a private staging repo per project, in ~/Library/Application Support/dotlore/.
  • Your project files stay where they are. Dotlore does not add anything to a project's git history.

What goes into your cloud folder

  • Git bundles of your included files, the project name, and each Mac's device ID and name. Your cloud provider's app uploads them, under its own privacy policy.
  • Protected files are encrypted (AES-SIV) before they are written. Other files are not.
  • Bundles are not encrypted by Dotlore. Anyone who can read that cloud folder can read the synced files, so do not put secrets in the include-list.

Removing your data

  • Settings → "Wipe cloud data" deletes the dotlore folder from your cloud folder.
  • To remove the local data, quit Dotlore and delete ~/Library/Application Support/dotlore/.
  • Local data. Quit Dotlore, delete ~/Library/Application Support/dotlore/, and remove the master-key-… item for dotlore in Keychain Access.

This website

  • Hosted on GitHub Pages, which may log IP addresses. No analytics or cookies; the theme choice is kept in local storage.
  • The Inter font comes from Google Fonts, and GitHub Releases counts downloads.

Questions

Dotlore is open source, so every claim here can be checked in the code. Questions? Open an issue on GitHub.
